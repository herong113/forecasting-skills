# 参考类预测(Reference Class Forecasting)

## 概述

用外部视角对抗规划谬误:不看项目内部细节,先看同类已完结案例的统计分布(基准线),再以分布为锚点做小幅、有客观依据的微调。方法论源自 Kahneman & Tversky,由 Bent Flyvbjerg 系统化为参考类预测(RCF);英国财政部 2003 年起将其强制用于公共项目评估。

## 三条铁律

1. **基线先行**:先拿到参考类的结果分布,再看项目自身细节。顺序不可颠倒——先看细节就会被内部视角锚定。
2. **数据只用官方来源**:基线数据必须来自官方统计、政府机构、同行评议学术研究或可追溯的权威行业报告,必须标注来源与年份。禁止使用无法追溯的数字;找不到可靠基线时明说"无可靠基线",绝不编造。
3. **微调必须客观**:对基线的调整只能基于可列举的客观差异因素,禁止"我更努力""这次不一样"式主观上调。

## 工作流程

### Step 0 锚定内部估计(先锁先验,再谈基线)

在引入任何基线数据之前,先拿到用户对工期/预算/成功率的主观估计及区间。这是被检验的先验——先锁定,可防止用户看到基线后重构原始估计。

**用户不是专业人士,全程大白话诱导,禁止出现"先验概率""置信区间"等术语。按以下阶梯推进:**

**① 套点估计**(从用户叙述自然过渡):

> "先不看任何外部数据——按你现在的打算,你估计几个月能完工?总共大概花多少万?做成的把握有多大?"

**② 套把握**(用户说不清百分比时,换具象刻度诱导):

> "打个比方:扔硬币猜正反面是 50% 的把握——你觉得你这事,比扔硬币稳多少?"

> 或自然频率法:"想象 100 个和你条件相当的人做同样的事,你猜大约几个能成?"

**③ 套区间**(先点后区,顺序不可颠倒——防止区间反向锚定点估计):

> "再想两个极端:一切顺利的话,最快几个月 / 最少多少万?(顺利到'比这更快不太可能'的程度)"
> "诸事不顺但仍然现实——不是天灾级——最晚几个月 / 最多多少万?"

**④ 套依据**(暴露估计的构成,供下游诊断):

> "你这个数字是怎么算出来的?主要算了哪几部分?"

**⑤ 中性复述锁定**:

> "记下了:工期 X 个月(区间 X~X),预算 X 万(区间 X~X),成功率 X%。"

只做复述,不做任何评价。

🛑 **STOP(Step 0 出口)**:内部估计未锁定前,禁止进入 Step 1。

**降级路径**(用户说"不知道 / 估不准"时逐级降级):

1. 换具象问法(硬币刻度 / 自然频率);
2. 拍脑袋法:"哪怕是拍脑袋——你脑子里冒出来的第一个数字是多少?"(第一数字就是内部视角的锚,同样有效);
3. 对赌诱导:"如果让你押 100 块钱赌'能成',你敢押吗?敢押多少?"(下注额换算主观把握)。

**快速通道(实战固化)**:同一问题连续 2 次被跳题,视为用户放弃该维度——标注"未提供"立即放行,禁止第三次追问;只锁到点估计也允许进入 Step 1。

**防污染规则(本步骤全程有效):**

- 不得透露任何基线信息;提问中不得夹带参考数字(连"比如 6 个月?"都不许——例子就是锚);
- 不做"你确定吗 / 会不会太乐观"式暗示性反应;
- 用户强调"我这次不一样"时,先接纳("你的具体情况第三步会专门处理"),但坚持先拿到数字;
- 记录打时间戳,报告中注明"内部估计记录于引入基线之前"。

**记录格式(统一):**

```text
内部估计(Step 0 锁定于 YYYY-MM-DD HH:MM,提问方式:标准 / 具象刻度 / 拍脑袋 / 对赌)
· 工期:点 X 月 [区间 X~X 月]
· 预算:点 X 万 [区间 X~X 万]
· 成功率:X%
· 依据构成:(用户自述的计算构成)
```

**下游用途:** 区间宽度用于"乐观偏差诊断"对照(主观区间通常过窄);依据构成暴露 WYSIATI(漏算审核/返工/等待),供 Step 3 微调与报告"偏差性质"栏使用。

### Step 0.5 范式三问(进基线之前的三道前置检查)

在选定参考类之前,先回答三个问题并把结论写进报告。三问决定"基线该怎么用、奇迹线在哪里":

**Q1 极限在哪里(第一性原理)?** 该领域的物理或逻辑极限是什么?用物理定律/数学约束/生理机制推导(如能量守恒、带宽、代谢速率上限),不看历史数据。产出:极限的推导依据 + 数值或量级。

**Q2 现状距极限多远(量级判断)?** 当前行业/同类的平均水平与极限差多少——10 倍、2 倍,还是仅 20%?量级决定奇迹线的想象空间:差 10 倍说明范式有巨大跃迁空间;仅差 20% 说明已接近天花板,"奇迹线"意义有限。

**Q3 历史数据是否同一范式?** 现有历史数据是否产生于与当前相同的技术范式之下?若不同(如数据来自纯行为干预时代,而现在已有药物/新工具),基线必须标注"旧范式基线",并单独检索新范式的可得数据;两者并列呈现,不可混用。

🔴 **CHECKPOINT**:三问结论先向用户展示(极限/空间/范式),再进入选定参考类。

### Step 1 选定参考类

通过 2~4 个问题界定参考类,按场景从 `references/question-bank.md` 选题。三条规则:

- **结构相似,不是人相似**:相似性看机制与结构(行业、规模、复杂度、依赖关系),不看"跟我一样聪明/努力"。
- **只用已完结案例**:参考类必须由已有最终结果的项目构成,进行中的项目不入类。
- **宽类优于窄类**:样本量优先;参考类不能窄到只剩"榜样案例"(幸存者偏差)。

### Step 2 画分布找基准线

获取参考类的结果分布。不许只给均值,必须给出:均值、中位数(比均值抗极端值)、尾部(最差 10%~20% 的样子)、失败率(多少比例根本没做成)。

数据源三级优先级:

1. 用户自身/所在组织的历史数据(最优,构成个性化参考类);
2. 联网检索官方统计/学术研究(按"数据源白名单",记录来源+年份+URL);
3. 内置经典数据集 `references/base-rates.md`(全部经核实、带来源)。

检索不到可靠数据时,在报告中明示"该维度无可靠基线",给方法指导但不填数字。

🔴 **CHECKPOINT**:向用户展示基线分布与来源清单后,再进入 Step 3 微调。

### Step 3 锚点微调

以基线分布为锚,评估当前项目在分布中的位置:

- 逐条列出与参考类中位水平的客观差异因素(团队同类经验、技术成熟度、规模相对位置、外部依赖数),每条注明方向与证据。
- 单因素调整限幅:工期/预算类不超过相邻一个分位档;成功率类按百分点小幅移动。
- 禁止笼统上调;没有客观证据时默认取中位数。

### Step 4 生成 HTML 预测报告

用 `assets/report-template.html` 生成单文件报告(复制模板→填充→present_files 交付)。报告必含模块见"输出契约"。对话中同步给出 TL;DR 结论(3~5 行),但完整交付物恒为 HTML 文件。

🛑 **STOP(交付前自检)**:对照"输出契约"第 1~7 项逐项核对,缺项补齐后方可 present_files 交付。报告文件生成或交付失败时,在对话内完整输出报告文本版兜底。

## 数据源白名单与可信度分级

- **A 级(官方统计/政府)**:US BLS、国家统计局、市场监管总局(原工商总局)、教育部、国家公务员局、国家卫健委、US CDC、HM Treasury/GOV.UK 等。
- **B 级(同行评议学术/作者原著)**:JAPA、HBR、NEJM、AJCN、JPSP 等期刊论文及作者原著(Flyvbjerg、Kahneman、Wing & Phelan、DPP/Look AHEAD 研究组等)。
- **C 级(权威行业报告)**:McKinsey Global Institute、Standish CHAOS、CB Insights 等——须标注商业机构性质与已知争议。
- **D 级(无可靠来源)**:禁止使用数字;报告中明示缺口,改指导用户自建微参考类(找 5~10 个结构相似的已完结案例)。

检索时排除:自媒体、营销号、无来源转载、AI 摘要站。每条入库数据必须可追溯到原始发布机构。

## 输出契约(HTML 报告必含模块)

**深入浅出双语规则(总注)**:专业术语保留,但每个专业词首次出现必须紧跟白话括号(≤20 字);结论条必须配一行"翻译"白话;每个表格的 note 以"这张表的意思:"或"简单说:"开头,用口语复述本表结论。白话只解释不扩写,不删术语、不替代数据。

**双线呈现规则**:预测必须同时给出两条线——①**参考类基线**(历史同类实然分布,默认决策依据);②**奇迹线**(依第一性原理/物理极限推导的最优解,须标注极限推导依据)。并附"奇迹线可行性分析":达成奇迹线需成立的假设(逐条编号)、难度排序与最难假设、终止条件(kill criteria:出现什么信号即停止加码)。

1. **结论条**:显式裁决——内部估计被基线【支持/不支持】+ 一句话理由。
2. **双线对比表**:内部估计 vs 参考类基线(均值/中位数/尾部/失败率) vs 调整后预测 vs **奇迹线**(第一性原理最优解);全量列直读,单位入表头。
3. **乐观偏差诊断**:内部估计落在基线分布的位置(分位/倍数);并对照其 Step 0 自报区间(主观区间通常过窄)。
4. **上浮对照表(uplift)**:给出 P50/P80/P95 把握度下需预留的工期/预算余量(方法参照英国 HM Treasury optimism bias 指南)。
5. **微调因素表**:因素 | 方向 | 客观依据 | 幅度。
6. **数据来源与可信度表**:每条基线数据的数值 | 来源机构 | 文献 | 年份 | 可信度等级(A/B/C)——**每份报告必填,不得省略**。
7. **方法与局限**脚注:参考类构成、口径说明;个人决策场景加伦理提示(基线是统计参考,不是命运判决)。
8. **范式三问**:Step 0.5 的三问结论(极限在哪 / 距极限多远 / 历史数据是否同范式)。
9. **奇迹线可行性分析**:假设分解(逐条编号) | 难度排序 | 最难假设 | 终止条件。

## 护栏

- 用户要求跳过流程直接要答案时:告知"先花 1 分钟锁定你的估计,之后全流程加速";用户坚持拒绝锁定时,产出"仅基线"版报告并在报告标注"无内部估计对照",不编造其估计。
- 个人决策场景(婚恋/生育/健康)保持克制:只呈现分布与调整逻辑,不下"该不该做"的判决。
- 用户试图用内部视角反驳基线时,承认其特殊性但坚持:特殊性只能进入 Step 3 的有限微调,不能替换基线。
- 工期/预算与成功率混问时,拆成两次预测,同报告分节呈现。
- 数字一律保留原始精度与口径;换算时必须注明。
- 奇迹线必须锚在物理定律或第一性原理上(给出推导依据),禁止用"理论上可以"包装无依据的乐观;奇迹线不得替代基线成为默认决策依据。
- 若 Step 0.5-Q3 判定历史数据属旧范式,基线必须标注"旧范式基线",并单独列出新范式可得数据(无则标 D 级),两者并列不混用。

## 资源

- `references/base-rates.md`:经典基线数据集(官方来源,含数值、样本、口径、年份、链接、可信度)。
- `references/question-bank.md`:三类场景的参考类界定问题库与防特殊化追问。
- `assets/report-template.html`:射表式 HTML 预测报告模板(浅色、单位入表头、等宽数字、来源标识区)。
