# 参考类界定问题库

用于 Step 1。按场景选 2~4 问,目标是锁定一个"结构相似、案例已完结、样本足够"的参考类。用户信息已足够时不必逐问,直接确认参考类即可。

---

## 场景 A:项目工期与预算

1. 项目属于哪一类?(软件/App、工程/装修、写作/内容制作、活动筹备、新产品开发……)
2. 规模量级?(预算区间 / 团队人数 / 计划工期)——用于对齐基线的规模口径。
3. 团队做过几个同类项目?(0 个 / 1~2 个 / ≥3 个)——对组织而言"非例行"的项目乐观偏差最大,第 0 次做必须靠基线。
4. 外部依赖有哪些?(审批、供应商、跨团队协作的数量)——依赖越多越靠近分布尾部。

参考类定位示例:

- "3~5 人团队、6 个月量级、首次自研的 App 开发项目" → 匹配 base-rates 1.3(IT/软件)+ 1.5(任务低估)。
- "120 平米旧房全屋翻新" → 1.1/1.2 相邻类(建筑),降可信度标注;同时建议用户向装修公司索取其过往 5~10 个已完结项目的实际结算 vs 报价分布(个性化参考类)。
- "写一本 20 万字的书" → 1.5(教材/写作案例)。

## 场景 B:创业与商业项目

1. 行业与业态?(餐饮/零售/线上服务/制造/内容变现……)
2. 雇主实体还是个体副业?(BLS 与工商总局口径均为 employer establishments;纯副业失败率更高但无官方数据,需标注)
3. 所在地区与启动资金量级?(对齐基线的口径;中国用户优先用 2.2,海外业务用 2.1)
4. 是否已有同业态经营数据?(自己、合伙人或加盟体系的过往项目)——有则优先,构成个性化参考类。

参考类定位示例:

- "在三线城市开一家社区咖啡馆" → 2.2(中国企业存活,住宿餐饮业备注)+ 2.1(BLS 行业细分)双源对照。
- "做一个工具类 App 并期望 12 个月内盈利" → 2.1 信息/科技细分(5 年失败约 61%)+ 2.3(失败原因结构)。
- "加盟连锁餐饮" → 2.2 + 提示索取该加盟品牌已闭店门店比例(可验证数据)。

## 场景 C:个人重大决策

1. 决策类型?(考学/转行/写作/减重/婚恋/生育……)
2. 可比人群的结构条件?(学历层次、年龄段、基础水平、每日可投入时间)——只看结构条件,不看"意志力"。
3. 时间窗与成功定义?("一次上岸" vs "两年内上岸";"减 10% 并维持一年" vs "减到目标体重")
4. 身边可观察的已完结案例有几个?(≥5 个即可自建微参考类:数出其中达到你成功定义的比例)

参考类定位示例:

- "在职备考国考,想一次上岸" → 3.1(考录比)+ 追问目标岗位层级(全国均值 65:1 与热门岗 6,470:1 是两个分布)。
- "半年减 15 斤并长期保持" → 3.2(约 20% 长期成功)+ 微调因素:是否有每日 1 小时运动的客观条件(NWCR 成功者的共同行为)。
- "转行做自由职业" → 无官方基线,走 3.4 路径:让用户列出 5~10 个已转行 ≥2 年的熟人案例,数存活比例。

## 通用追问(防特殊化)

- "你认为你的项目和这类项目的典型水平相比,最强的**客观**差异是什么?"——只接受可验证事实(资质、过往交付记录、资金储备),不接受"我更努力""我很重视"。
- "如果把这个项目交给另一个条件相当的团队/人,你会怎么估?"——去自我化提问,答案往往更接近基线。
- "你估计的把握有多大?如果按这个把握打赌,你愿意下什么注?"——暴露内部估计的真实置信度,便于与基线分位对照。
